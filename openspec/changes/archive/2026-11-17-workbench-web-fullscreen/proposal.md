## Why

TUI、Shell 与 Git 共用任务工作台，但全局侧栏和任务页头持续占用可视空间，限制终端输出与代码 diff 的阅读和操作面积。需要一种网页内沉浸模式，让用户在不离开当前工作台、不中断终端或 Git 状态的前提下专注工作，并允许按个人习惯配置切换快捷键。

## What Changes

- 为任务工作台的 TUI、Shell、Git 标签增加网页内全屏（Zen）模式，隐藏全局侧栏和任务页头，并保留标签栏、ServerStatusBanner 及明确的全屏退出入口。
- 桌面端 Zen 默认提供专用任务状态窄栏，仅展示任务状态与当前任务标识，不包含品牌、全局导航或侧栏底栏；用户可从窄栏底部隐藏它，并通过保留的展开入口恢复。移动端不展示任务窄栏。窄栏显隐仅属于当前 Zen 会话，不修改全局侧栏偏好。
- 全局折叠侧栏与 Zen 任务窄栏统一使用无额外延迟的自定义任务悬浮详情，替代缓慢的原生 `title` 提示，展示任务名、所属项目、状态及待处理数量。
- 在标签栏提供 `zen` / `out zen` 按钮，并提供可配置的工作台全屏热键；`Esc` 保持现有终端及应用行为，不作为全屏退出快捷键。
- 在全局设置页增加独立的全屏热键配置并持久化，保存后在当前应用实例生效，且不得与现有快捷键或浏览器保留组合冲突。
- 全屏期间仍可在 TUI、Shell、Git 之间切换；进入“设置”后也保持 Zen、任务轨显隐和固定退出入口，普通设置页不允许通过热键首次进入 Zen。
- 全屏开关状态仅属于当前工作台会话，切换任务、离开页面或刷新后恢复普通布局，不写入持久化存储；全屏热键偏好作为独立配置持久化。
- 保持现有终端、Shell 和 Git 面板常驻及尺寸自适应行为，不因进入或退出全屏而重建工作内容。
- 本期不调用浏览器原生 Fullscreen API，不提供独立 pane 全屏，也不改变终端 WebSocket 协议。

## Capabilities

### New Capabilities

无。

### Modified Capabilities

- `web-ui-shell`: 增加任务工作台网页内全屏的布局、入口、标签切换、退出及状态生命周期行为契约，并为移动端任务导航补充全屏期间的临时隐藏例外。
- `palette-config`: 在现有配置存储、读写 API 与设置页中增加独立的工作台全屏热键及跨动作冲突校验、旧配置兼容行为。

## Impact

- 影响 React 任务工作台、全局应用壳层、设置页及相关 CSS，主要涉及 `TaskWorkbenchPage`、`AppShell`、命令面板配置面板和工作台样式。
- 扩展现有 palette 配置类型、`GET/PUT /api/v1/palette/config`、配置文件兼容迁移与前后端热键校验；不新增后端 API 路由。
- 需要覆盖全屏切换、配置化快捷键、冲突校验、旧配置迁移、标签行为、状态重置及终端/Git 尺寸适配的前后端测试。
- 不涉及任务数据模型、终端 WebSocket 协议或新增第三方依赖。
