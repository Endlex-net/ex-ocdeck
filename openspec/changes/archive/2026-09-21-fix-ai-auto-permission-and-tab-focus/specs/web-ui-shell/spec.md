## ADDED Requirements

### Requirement: 任务详情页终端 tab 切换聚焦

用户在任务详情页点击「终端」或某个「shell N」标签页后，系统 SHALL 将键盘焦点转移到该标签页对应终端的输入，使后续键盘输入直接作用于该终端。重复点击已激活的终端标签页 MUST 同样产生聚焦。「Git」「设置」标签页以及非用户点击导致的程序性标签页切换 MUST NOT 产生聚焦。聚焦 MUST 在对应终端就绪（可接收输入）后生效；点击时终端未就绪的，聚焦在就绪后生效，但等待必须有界（超时放弃本次聚焦，参数见 design）。聚焦 MUST NOT 抢占用户已转移的输入焦点：聚焦生效前若用户焦点已进入任何输入区（编辑器、提交框、文本框等），系统 MUST 取消本次聚焦。目标终端处于锁定状态（见 `terminal-streaming` spec「触屏设备终端输入锁定」）时 MUST NOT 强制聚焦。等待就绪期间用户切换到其他标签页或离开任务详情页时，本次聚焦 MUST 取消。既有任务导航聚焦（见「侧栏任务导航后焦点落到终端」）行为 MUST 保持不变：shell 终端 MUST NOT 因任务导航入口（侧栏任务项、工作台任务切换器、指挥中心任务行）点击而被聚焦。

#### Scenario: 点击终端标签页聚焦 TUI

- **WHEN** 用户在任务详情页点击「终端」标签页，TUI 终端渲染就绪
- **THEN** 键盘焦点位于 TUI 终端输入，后续键盘输入直接作用于 TUI

#### Scenario: 点击 shell 标签页聚焦对应 shell

- **WHEN** 用户在任务详情页点击某个「shell N」标签页，该 shell 终端渲染就绪
- **THEN** 键盘焦点位于该 shell 终端输入，后续键盘输入直接作用于该 shell

#### Scenario: 重复点击已激活终端标签页仍聚焦

- **WHEN** 当前已是某终端标签页，用户焦点已移出终端（如点击了页面其他区域），再次点击该同一终端标签页
- **THEN** 键盘焦点重新转移到该终端输入

#### Scenario: 非终端标签页不聚焦

- **WHEN** 用户点击「Git」或「设置」标签页
- **THEN** 系统 MUST NOT 将键盘焦点转移到任何终端

#### Scenario: 不抢占用户输入焦点

- **WHEN** 用户点击终端标签页后终端尚未就绪期间，用户已将焦点移入提交框等输入区
- **THEN** 终端就绪后 MUST NOT 抢夺焦点，用户输入不被打断

#### Scenario: 终端锁定时不强制聚焦

- **WHEN** 终端锁定能力启用且目标终端处于锁定状态，用户点击其标签页
- **THEN** 系统 MUST NOT 聚焦终端 textarea，锁定状态保持

#### Scenario: 等待就绪期间离开则取消

- **WHEN** 用户点击终端标签页后终端尚未就绪，随后用户切换到其他标签页或离开任务详情页
- **THEN** 该次聚焦请求取消，终端后续就绪时 MUST NOT 聚焦
