# Proposal: diff-review-workbench

## Why

git diff 页面目前只提供查看 diff 与提交的基础只读能力。用户在 review AI 多轮修改时发现的问题，只能转述到终端让 AI 逐一修复（需手工描述文件与行号），或离开 diff 页手动修改，反馈回路慢且打断 review 心流。需要一个把「批注反馈 → 整体提交给 AI 修复」与「顺手小修」直接落在 diff 页上的能力。

## What Changes

- **diff 批注**：在 git diff 页面的查看模式下，通过框选段落或点击行创建评论批注，批注记录文件、行位置、选中代码原文（含周边上下文行，避免定位歧义）与用户评论，可跨多轮编辑/AI 修改持续累积；已批注的行在 diff 中有弱存在感标记，不遮挡代码内容；未输入评论的批注不留存。
- **批注状态**：批注具有锚定有效/已漂移两种状态；代码变化导致锚点失配时转为已漂移，仍可提交，但界面必须标记其漂移状态。
- **批注提交给 AI**：批注列表支持查看、编辑、删除（误删不提供撤回）；提交时先经预览确认（可临时移除条目、在可折叠补充说明框中补充整体意图），随后由后端将批注连同相关代码改动上下文一起提交给当前 task 的 AI agent 会话执行整体修复。提交内容包含文件与行号、代码原文快照（含上下文行）、评论、补充说明及相关 diff，并具有体积保护与可感知的截断行为。
- **排队与撤回**：agent 忙时允许排队，排队中的提交可撤回；提交结果跨服务重启不丢失，任何提交至多投递一次。
- **提交清空与历史**：提交成功投递后仅清空本次实际提交的批注（预览中临时移除的条目保留在活动批注列表），并将该次提交归档为只读、可删除的历史记录，用于回看与防止内容丢失。
- **diff 直接编辑**：diff 页面在原有只读查看之外新增编辑模式；查看模式承担批注，编辑模式承担直接修改。编辑模式下可直接修改文件内容并实时生效（无保存按钮、无脏状态概念），始终提供「还原本文件的修改」入口；写回不得无意改变原文件的换行风格与编码。
- **特殊文件边界**：针对 binary、truncated、untracked 等特殊文件状态，必须定义查看、批注、编辑的可用能力边界（具体取值在设计阶段确定）。

## 范围边界与非目标

- 不产生真实 git commit 的语义变化，不改变 git 历史。
- 修复执行者始终是当前 task 的 agent 会话：批注由后端直接投递到该会话执行整体修复；不经平台 LLM 直连生成 patch。目标环境不具备投递能力时的降级只允许「能力禁用或明确报错」，不得改走其他 AI 通道。
- 编辑能力定位为 review 顺手小修，不做 IDE 级编辑能力。
- 不做新用户引导；不做 AI 处理状态徽标、完成通知与 diff 静默刷新保护；历史记录为纯只读列表，不提供到当前代码的验收跳转；误删批注不提供撤回。
- agent 忙时编辑模式的宽严策略不在本 proposal 定案，留设计阶段决定。

## 验收边界

端到端可走通：在 diff 页打批注 → 多轮累积 → 预览提交 → task agent 会话执行整体修复；编辑模式下修改实时生效。

## Capabilities

### New Capabilities

- `diff-annotations`: diff 页面上的批注创建（框选/点击）、行内标记、批注列表管理、整体提交给 task agent 会话（含排队、撤回、持久化与重启恢复）、提交历史持久化。

### Modified Capabilities

- `git-operations`: diff 查看新增「查看/编辑」两模式，编辑模式下的文件直接修改、实时生效、写回保真与还原入口。

## Impact

- **前端**：`web/src/components/GitPanel.tsx`、`web/src/components/diff/DiffViewer.tsx`（CodeMirror MergeView）、`web/src/types.ts`、`web/src/api.ts`。
- **后端**：`internal/api`（新增批注/提交/历史/文件写回路由）、`internal/task`（facade）、`internal/infrastructure/opencode/client.go`（新增向 agent 会话发送消息的方法）、SQLite 新增批注与提交/历史持久化。
- **外部契约**：依赖 opencode 本地 HTTP server 的消息发送能力；目标环境不具备该能力时按范围边界中的降级约束处理。
- **OpenSpec**：新增 `diff-annotations` spec；`git-operations` spec 增加 delta。
