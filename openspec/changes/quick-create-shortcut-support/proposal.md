# Proposal: quick-create-shortcut-support

## Why

⌘K 命令面板目前输入 `new` 只能跳到新建任务面板，项目仍需手动选择，快捷录入不完整；同时命令面板的唤起热键、快速新建触发词与匹配行为全部硬编码，用户无法按习惯配置。

## What Changes

- 命令面板支持「触发词 + 项目名」快速新建（项目名可包含空格）：输入完整后按 Enter，打开指挥中心新建任务面板，项目可自动预选，光标落在任务名输入框；项目无法预选时用户手动续选。
- 项目名匹配与候选排序设计为可复用的通用机制，供命令面板候选列表及未来场景（任务搜索、项目选择器等）复用。
- 现有 `new`（无参数）跳转新建任务面板的行为保持不变。
- 设置页新增「命令面板」配置子标签，提供命令面板配置：
  - 唤起热键自定义（默认 ⌘K / Ctrl+K）
  - 快速新建触发词自定义（默认 `new`）
  - 项目名匹配模式设置
- 新增后端配置读写接口，配置持久化到后端配置文件。

## Capabilities

### New Capabilities

- `palette-config`: 命令面板配置的持久化存储与读写 API（热键、触发词、匹配模式），及设置页「命令面板」配置子标签。

### Modified Capabilities

- `web-ui-shell`: ⌘K 命令面板新增触发词解析与快速新建入口；唤起热键改为可配置。
- `command-center`: 新建任务面板支持来自命令面板的「预选项目 + 聚焦任务名」初始化信号。

## Impact

- 前端：`App`（配置加载与热键监听）、`CommandPalette`（触发词解析、快速新建入口）、`NewTaskPanel`（预选项目初始化）、`SettingsPage` + 新增「命令面板」配置面板组件、`router`（新子标签）。
- 后端：新增 palette 配置存储（应用数据目录下配置文件）与读写 API，服务启动接线。
- 测试：前端面板解析/配置页测试，后端配置存储与 API 测试。

## 范围边界与非目标

- 不支持「触发词 + 项目名 + 任务名」一次录入任务名。
- 不新增中文内置触发词；快速新建触发词支持自定义。
- 不改造其他全局热键（如 ⌘B），不做全局快捷键管理系统。
- 不提供 per-browser 配置覆盖。
